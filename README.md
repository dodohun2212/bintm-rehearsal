- 저장소: https://github.com/dodohun2212/bintm-rehearsal

- 앱이 잠들어 있으면 "Yes, get this app back up!"을 누르고 30초쯤 기다려 주세요.
- **결과 예시**: 앱을 열지 않고 읽기 → [`docs/결과_예시/`](docs/결과_예시/README.md) (배포 앱에서 실제 AI로 돌려 내려받은 파일)
- **테스트**: `python -m pytest -q tests/` → 79 passed (AI 호출 없음).
- **배포 URL 실제 AI 한 바퀴** (2026-11-11, 앱 ⑤ 사용량): 분석 57.4초 + 문제 만들기 21.2초 + 채점 3.8초 + 보완 설명 19.0초 + 요약 노트 22.5초 = 약 124초, AI 호출 28번, 실패 0.
- **핵심 설계**: 점수·순위·이해 상태는 코드가 정하고(`core/score.py`, `core/priority.py`), AI는 읽고 분류하고 설명만 합니다.
- **가장 큰 한계**: 출제 가능성 가중치(v0)는 가상 샘플 자료로만 맞췄고, 실제 기출로 검증하지 않았습니다.

## 무엇을 하는 앱인지

**① 출제 포인트 레이더.** 자료 전체에서 개념을 뽑고(AI 호출 1), 녹음 대본에서 교수님의 강조·시험 암시·실수 경고·연습문제 지목·"다음에 다룸"을 찾습니다(AI 호출 2, 대본에 실제로 있는 문장만). 코드가 정해진 가중치로 점수를 더해 가장 높은 개념을 100점으로 맞춘 비교용 점수(확률 아님)와 근거 배지를 보여 줍니다.

**② 내 취약점 진단.** 출제 점수 20점 이상 개념 **전부**를 문제로 냅니다(섞어서: 50점 이상 서술형, 미만 객관식). 객관식은 코드가 채점하고 "확신 없이 골랐어요"로 맞히면 '헷갈림', 서술형은 AI가 루브릭으로 채점하지만 총점과 상태(8↑ 앎, 4~7 헷갈림, 3↓ 모름, "개념 혼동"은 모름)는 코드가 정합니다. 모든 문제에 답해야 채점합니다.

**③ 우선순위 보완 학습.** 우선순위 = 출제 점수 × (1 − 이해도). '지금 당장 · 다음 · 복습만'으로 묶고, 카드마다 내 문제와 답·채점·정답과 자료 페이지를 인용한 보완 설명을 한 장에 담습니다. 보완 설명은 **'지금 당장' 전부, 우선순위 상위 3개, 객관식에서 헷갈린 점을 적은 개념**만 자동으로 만들고, 나머지는 카드의 "설명 보기"나 "'다음' 개념 설명 한 번에 보기" 버튼으로 만듭니다. 근거 페이지는 PDF 원본 그림으로도 볼 수 있습니다.

**④ 시험 대비 요약 노트.** 강의 순서대로 모든 개념을 정리합니다. 지금 당장·출제 점수 50점 이상·진단 모름은 "자세히", 다음·헷갈림은 "보통"(AI 호출 5), 나머지는 "짧게"(AI 없이 개념 요약 한 줄). 교수님 말은 AI가 아니라 코드가 대본 인용을 그대로 붙입니다.

내려받기: 공부 순서·오답노트 HTML과 요약 노트 HTML 두 파일(페이지 그림 없음, 인터넷 없이 열림). 실제로 내려받은 파일과 같은 내용의 마크다운은 [결과 예시](docs/결과_예시/README.md)에 있습니다. 스크린샷은 이번에 찍지 못했습니다.

## 사용 방법

- 앱이 잠들어 있으면 "Yes, get this app back up!"을 누르고 30초쯤 기다립니다.
- **샘플로 체험**: ①에서 "🧪 샘플 자료로 체험하기". 문제를 다 풀 시간이 없으면 ③에서 "예시 답 채우기 (샘플 체험용)"를 누르면 앎·헷갈림·모름이 모두 나오는 답이 채워집니다.
- **내 자료**: PDF·PPTX(30MB까지) + 녹음(m4a·mp3·wav 25MB, 음성 인식 키가 있을 때) 또는 대본 붙여넣기. 녹음·대본이 없어도 됩니다(녹음 신호만 0).
- **빠른 진단**: ②의 토글. 직접 올린 자료는 진단 대상이 8개보다 많으면 기본으로 켜져 상위 5개만 풉니다(샘플은 꺼짐).
- **배포 앱 사용 제한**: 화면(세션)당 분석 5번, 서버 전체 하루 분석 150번, 하루 AI 호출 3000번. 샘플 자료의 문제·보완 설명·요약 노트는 서버에 저장해 두 번째 사람부터는 AI를 부르지 않습니다.

## 어떻게 동작하는지

```
자료(PDF/PPTX) ─ 텍스트 추출·마스킹 ─ [AI 1 개념 추출] ┐
녹음/대본 ──── 받아쓰기·마스킹 ──── [AI 2 강조 발화] ┴─ 코드: 출제 점수 → ② 순위
② → [AI 3-A 서술형 / 3-C 객관식 문제] → 답 → 코드(객관식)·[AI 3-B 서술형 채점] → 코드: 이해 상태
→ 코드: 우선순위 → [AI 4 보완 설명] · [AI 5 요약 노트] → HTML 내려받기 2개
```

AI 3~5에는 그 개념의 근거 페이지 텍스트만(최대 8쪽) 넣습니다. 모든 AI 답은 JSON으로 받아 형식을 검사하고, 범위 밖 페이지 번호·본문 속 `(p.n)`은 코드가 지웁니다.

출제 가능성 가중치 (v0, `core/score.py` 맨 위 `WEIGHTS`):

| 신호 | 점수 |
|---|---|
| 학습목표에 있음 | +3.0 |
| 본문 쪽수(메타 페이지 제외) | 쪽당 +1.0, 최대 4쪽 |
| 예제·그림으로 과정 설명 | +1.5 |
| 연습문제에 포함 | +2.0 |
| 강조 / 시험 암시 / 실수 경고 / 연습문제 지목 | +1.0 / +1.5 / +0.7 / +1.0 × (강도/3), 발화마다 |
| 다음에 다룸 / 가볍게 넘어감 | −2.5 / −1.0, 발화마다 |

이해도: 앎 1.0 · 헷갈림 0.5 · 모름 0 · 진단 안 함 0.5. 우선순위 50 이상 지금 당장, 20~49 다음, 20 미만 복습만.

모델: `claude-sonnet-5-5`. 바꾸려면 `config.py`의 `LLM_MODEL` 한 줄만 고칩니다. 모든 호출은 `core/llm.py`의 `ask_json()` 하나를 거칩니다(스트리밍, 재시도, 호출당 90초 상한).

## 로컬 실행

```bash
python -m pip install -r requirements.txt
```

`.streamlit/secrets.toml`을 만들고 키 이름만 적습니다(값은 각자 발급, 저장소에 올리지 않음):

```toml
ANTHROPIC_API_KEY = "..."
OPENAI_API_KEY = "..."   # 녹음 받아쓰기를 쓸 때만
```

```bash
python -m streamlit run app.py
```

키 없이 화면만 보려면 `BINTM_FAKE_AI=1`로 실행합니다(저장된 결과로 답하는 가짜 AI).

## 한계와 향후 계획

- 스캔 PDF(글자가 그림인 PDF)는 읽지 못합니다(E-03 안내). 한 번에 한 장(chapter) 단위를 전제로 하고 120쪽까지만 분석합니다.
- 녹음은 25MB까지. 음성 인식 키가 없으면 대본 붙여넣기만 됩니다.
- 출제 점수는 규칙 기반 추정입니다. 가중치 v0는 가상 샘플 자료로만 맞췄고 실제 기출로 검증하지 않았습니다(`scripts/compare_exam.py`로 비교할 수 있게 해 두었습니다).
- 새로고침하면 결과가 사라집니다. ④에서 HTML로 내려받아 보관하세요. 결과 저장·불러오기(JSON)는 이번에 만들지 않았습니다.
- 분석·AI 호출 횟수는 서버 메모리에서 세므로 서버가 다시 켜지면 0부터 셉니다.
- 향후: 모델 교체 비교, 학우 질문 기록(F12).

## 데이터 처리·저작권·녹음 동의

- 올린 파일과 결과는 서버 디스크에 쓰지 않습니다. 결과는 브라우저 세션에만 있고, 같은 파일의 개념·강조 분석 결과와 쪽 그림만 서버 메모리 캐시에 둡니다.
- 학번·주민등록번호·전화번호·이메일은 AI에 보내기 전에 `[마스킹]`으로 가립니다(강의 자료와 대본 모두).
- 샘플 자료는 팀이 직접 만든 가상 자료입니다. 실제 교재·녹음은 저장소에 넣지 않습니다.
- 녹음은 교수님 허락을 받고 개인 학습 목적으로만 써 주세요.
