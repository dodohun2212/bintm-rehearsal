# 빈틈노트

강의자료와 교수님 강의 녹음(또는 대본)을 올리면, 출제 신호로 개념 순위를 매기고, 진단 문제로 내 빈틈을 찾아, 시험 전 공부 순서와 오답노트·요약 노트를 만들어 주는 앱입니다.

- 배포 URL: https://bintm-rehearsal-myagsiaqtsuzkjjrnnrpgc.streamlit.app
- 저장소: https://github.com/dodohun2212/bintm-rehearsal
- **출제를 보장하지 않습니다. 공부 우선순위를 정하는 참고용입니다**

## 심사용 요약

- **무엇**: 강의자료 + 녹음 → ① 출제 포인트 순위 → ② 객관식·서술형 진단(찍어서 맞힌 것은 '헷갈림') → ③ 출제 점수 × 모르는 정도로 공부 순서와 오답노트 → ④ 강의 순서 요약 노트
- **1분 체험**: 샘플로 체험 → "12개 개념 진단하기" → "예시 답 채우기 (샘플 체험용)" → "채점하기" → "공부 순서 보기" (개수는 AI가 찾은 개념에 따라 달라질 수 있음)
- **앱이 잠들었으면**: "Yes, get this app back up!"을 누르고 30초쯤 기다립니다
- **결과 예시**(앱을 열지 않고 읽기): [docs/결과_예시/README.md](docs/결과_예시/README.md)
- **테스트**: 자동 테스트 96개 통과 (`python -m pytest -q tests/`, 가짜 AI, 키 없음) · GitHub Actions에서도 실행
- **실제 AI 한 바퀴**(배포 URL, 샘플): 단계별 시간 합 106.5초, 실패 0 (앱 ⑤ 사용량에서 읽은 값, 아래 "테스트")
- **핵심 설계**: 점수·순위·이해 상태 판정은 코드(`core/score.py`, `core/priority.py`)가 하고, AI는 읽고 분류하고 설명만 합니다
- **가장 큰 한계**: 가중치 v0는 가상 샘플 자료의 신호표로만 맞췄고, 실제 기출로는 아직 검증하지 않았습니다

## 무엇을 하는 앱인지

**① 출제 포인트 레이더 (S02)**
- AI가 자료에서 개념과 메타 페이지(표지·목차·학습목표·연습문제·요약)를, 대본에서 교수님의 강조·시험 암시·실수 경고·연습문제 지목·미룸·넘어감 발화를 찾습니다.
- 코드가 정해진 가중치로 더해 가장 높은 개념을 100점으로 둔 **출제 가능성 점수**(확률이 아닌 비교용 점수)를 만듭니다.
- 개념마다 근거 배지(학습목표 · 본문 n쪽 · 예제 · 연습문제 · 강조 ×n …)와 교수님 말 원문을 보여 줍니다.

**② 내 취약점 진단 (S03)**
- 출제 점수 20점 이상인 개념 **전부**를 문제로 냅니다(섞어서: 50점 이상 서술형, 나머지 객관식). 직접 올린 자료는 대상이 8개보다 많으면 "빠른 진단(상위 5개)"이 기본으로 켜집니다.
- 객관식은 코드가 채점하고 "확신 없이 골랐어요"로 맞히면 '헷갈림'입니다. 헷갈린 점을 적을 수 있습니다. 서술형은 AI가 루브릭으로 채점하고 상태는 코드가 점수로 정합니다.
- 트리·배열·표가 필요한 문제는 AI가 데이터로 주고 코드가 그림으로 그립니다. 모든 문제에 답해야 채점합니다.

**③ 우선순위 보완 학습 (S04 첫 탭)**
- 우선순위 = 출제 점수 × (1 − 이해도)로 "지금 당장 · 다음 · 복습만"을 나누고, 카드마다 내 문제와 답·채점·정답을 다시 보여 줍니다.
- 보완 설명은 **"지금 당장" 전부, 우선순위 상위 3개, 헷갈린 점을 적은 개념**만 자동으로 만들고, 나머지는 카드의 "설명 보기"나 "'다음' 개념 설명 한 번에 보기" 버튼으로 만듭니다. 설명은 자료 문장을 인용해 `p.n`을 붙이고, 모름·헷갈림이면 마지막 문단에서 내가 푼 그 문제를 정답까지 풀어 줍니다. 자료에 없으면 "올린 자료에서 찾지 못함"으로 표시합니다.
- 근거 페이지의 원본 그림(PDF)을 펼쳐 볼 수 있습니다.

**④ 시험 대비 요약 노트 (S04 둘째 탭)**
- 강의 순서(개념이 본문에 처음 나오는 쪽)대로 모든 개념을 정리합니다.
- 자세한 정도는 코드가 정합니다(자세히: 지금 당장·출제 점수 50점 이상·진단 모름 / 보통: 다음·헷갈림 / 짧게: 나머지, AI 호출 없음).
- 교수님 말은 AI가 아니라 코드가 녹음 결과에서 붙이고 "녹음" 배지를 답니다. 결과는 HTML 2개(공부 순서·오답노트, 요약 노트)로 내려받습니다.

결과가 어떻게 생겼는지는 [결과 예시](docs/결과_예시/README.md)(배포 앱에서 내려받은 파일 그대로 + 마크다운)를 보세요.

## 사용 방법

- 배포 앱이 잠들어 있으면 "Yes, get this app back up!"을 누르고 30초쯤 기다립니다.
- **샘플로 체험**: 파일 없이 "🧪 샘플로 체험"을 누릅니다(직접 만든 가상 강의자료 20쪽 + 대본). 문제를 다 풀 시간이 없으면 ③에서 "예시 답 채우기 (샘플 체험용)"를 누릅니다(앎·헷갈림·모름이 모두 나오게 돌려 가며 채움, 채운 뒤 고쳐도 됨).
- **내 자료 올리기**: PDF/PPTX(최대 30MB) + 녹음(m4a/mp3/wav, 최대 25MB) 또는 대본을 넣고 "분석 시작".
- **녹음 대신 대본**: "📝 대본 붙여넣기" 탭에 받아쓰기 앱으로 만든 대본을 붙여 넣습니다. 둘 다 없어도 동작합니다(녹음 신호만 0).
- **빠른 진단**: ②의 토글. 출제 가능성 상위 5개만 풀고 나머지는 '진단 안 함'(이해도 0.5)으로 계산합니다.
- **배포 앱의 사용 제한**(운영자 키 하나를 모두가 쓰므로): 화면(세션)당 분석 5번, 서버 전체 하루 분석 150번, 하루 AI 호출 3000번. 저장된 결과만으로 끝난 분석은 하루 횟수에서 빼지 않습니다.

## 어떻게 동작하는지

```text
자료(PDF/PPTX) ─ 추출·마스킹 ─▶ [AI 1 개념 추출] ─┐
녹음 ─ [음성 인식] ─ 대본 ─ 마스킹 ─▶ [AI 2 강조 발화] ─┴▶ 코드: 출제 점수(8.1 가중치) ─▶ ② 순위
                                    [AI 3-A 서술형 · 3-C 객관식 문제] ─▶ ③ 답 입력
                    객관식·모르겠어요 = 코드 채점 / 서술형 = [AI 3-B 루브릭 채점] ─▶ 코드: 이해 상태
                    코드: 우선순위 ─▶ [AI 4 보완 설명] ─▶ ④ 첫 탭 / [AI 5 요약 노트] ─▶ ④ 둘째 탭 ─▶ HTML 2개
```

- AI 호출 3·4·5에는 그 개념의 근거 쪽 텍스트만(최대 8쪽) 넣습니다. 모든 응답은 JSON으로 받아 형식을 검사하고, 범위 밖 페이지 번호와 본문 속 `(p.n)`은 코드가 지웁니다.
- 출제 가능성 점수 가중치(v0, `core/score.py` 맨 위 `WEIGHTS`):

| 신호 | 점수 |
|---|---|
| 학습목표에 있음 | +3.0 |
| 본문 쪽수(메타 페이지 제외) | 쪽당 +1.0, 최대 +4.0 |
| 예제·그림으로 과정 설명 | +1.5 |
| 연습문제에 포함 | +2.0 |
| 강조 / 시험 암시 / 실수 경고 / 연습문제 지목 | +1.0 / +1.5 / +0.7 / +1.0 (× 강도/3, 발화마다) |
| 다음에 다룸 / 가볍게 넘어감 | −2.5 / −1.0 (발화마다) |

- 같은 입력이면(AI가 찾은 신호가 같으면) 같은 점수가 나옵니다. 가장 높은 개념이 100점입니다.
- 이해도: 앎 1.0 · 헷갈림 0.5 · 모름 0 · 진단 안 함 0.5. 서술형은 8점 이상 앎, 4~7 헷갈림("개념 혼동"이면 모름), 3 이하 모름.
- **우선순위 = round(출제 점수 × (1 − 이해도))**. 50 이상 지금 당장, 20~49 다음, 20 미만 복습만.
- 언어 모델: `claude-sonnet-5-5`. 바꾸려면 `config.py`의 `LLM_MODEL` 한 줄만 고칩니다. 음성 인식은 `STT_MODEL`(`whisper-1`).

## 로컬 실행

```bash
python -m pip install -r requirements.txt
```

`.streamlit/secrets.toml`을 만들어 키 이름 `ANTHROPIC_API_KEY`(녹음 받아쓰기를 쓰면 `OPENAI_API_KEY`도)를 적습니다. 이 파일은 `.gitignore`에 있습니다.

```bash
python -m streamlit run app.py
```

키 없이 화면만 보려면 환경변수 `BINTM_FAKE_AI=1`을 켭니다(저장된 결과로 답하는 가짜 AI). Windows에서 실행 파일이 막히면 위처럼 `python -m`으로 실행합니다.

## 한계와 향후 계획

- 스캔 PDF(글자가 그림인 PDF)는 읽지 못합니다(E-03 안내). 글자 인식은 향후 계획입니다.
- 한 번에 한 장(chapter) 단위를 전제로 하고 120쪽까지만 분석합니다. 녹음은 25MB까지입니다.
- 출제 가능성 점수는 규칙 기반 추정입니다. 가중치 v0는 가상 샘플의 신호표로만 맞췄고 실제 기출로는 검증하지 않았습니다.
- 새로고침하면 결과가 사라집니다. ④에서 HTML로 내려받아 보관하세요.
- 분석 횟수는 서버 메모리에서 세므로 서버가 다시 켜지면 하루 횟수가 0부터 다시 셉니다.
- 모델은 `config.py` 한 줄로 바꿀 수 있지만 다른 모델로는 확인하지 않았습니다. 학우 질문 기록(F12)은 만들지 않았습니다.

## 데이터 처리 · 저작권 · 녹음 동의

- 올린 자료와 녹음은 분석을 위해 AI 제공사(Anthropic, OpenAI) 서버로 전송됩니다.
- 올린 파일과 결과는 서버 디스크에 저장하지 않습니다. 결과는 브라우저 세션에 있고, 같은 파일을 다시 분석할 때를 위해 개념·강조 분석 결과와 쪽 그림, 샘플 자료의 진단 문제만 서버 메모리 캐시에 둡니다(서버가 다시 켜지면 사라짐).
- 학번(앞에 "학번"·"Student ID" 등이 있을 때)·주민등록번호·전화번호·이메일은 강의자료와 대본 모두 AI에 보내기 전에 `[마스킹]`으로 가립니다.
- 녹음은 교수님 허락을 받은 것만, 개인 학습 목적으로만 올려 주세요. 저장소에는 직접 만든 가상 샘플만 있습니다.
- API 키는 코드·저장소에 없고 `st.secrets` → 환경변수 순으로만 읽습니다.
