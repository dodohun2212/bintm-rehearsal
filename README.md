# 빈틈노트

강의자료와 교수님 강의 녹음(또는 대본)으로 시험 전 공부 우선순위를 정해 주는 AI 학습 도우미입니다.

- 배포 URL: https://bintm-rehearsal-myagsiaqtsuzkjjrnnrpgc.streamlit.app
- 저장소: https://github.com/dodohun2212/bintm-rehearsal
- **출제를 보장하지 않습니다. 공부 우선순위를 정하는 참고용입니다.**

## 무엇을 하는 앱인가

**① 출제 포인트 레이더.** 강의자료(PDF/PPTX)에서 개념을 뽑고, 녹음 대본에서 교수님이 강조·시험 암시·실수 경고한 말을 찾습니다.
학습목표·본문 쪽수·예제·연습문제·교수님 말을 정해진 가중치로 더해 개념마다 출제 가능성 점수(가장 높은 개념 = 100점)를 냅니다.
점수는 AI가 아니라 코드가 계산하므로 AI가 찾은 신호가 같으면 같은 점수가 나옵니다.

**② 내 취약점 진단.** 출제 가능성 점수 20점 이상인 개념 전부를 진단 문제로 확인합니다(섞어서: 50점 이상 서술형, 나머지 객관식).
객관식은 "확신 없이 골랐어요"를 체크하면 맞혀도 '헷갈림'으로 봅니다. 찍어서 맞힌 것과 아는 것을 나누는 것이 핵심입니다.
서술형은 AI가 루브릭으로 채점하고, 상태(앎·헷갈림·모름)는 코드가 점수로 정합니다.

**③ 우선순위 보완 학습.** 출제 점수 × (1 − 이해도)로 공부 순서(지금 당장·다음·복습만)를 정합니다.
개념마다 내 문제와 답, 채점, 정답과 자료 페이지를 인용한 보완 설명을 오답노트 한 장에 담습니다.
자료에 없는 내용은 지어내지 않고 "올린 자료에서 찾지 못함"으로 표시합니다.

**④ 시험 대비 요약 노트.** 강의 순서대로 모든 개념을 정리하되, 중요한 개념일수록 자세히 씁니다.
교수님 말은 AI가 아니라 코드가 녹음 분석 결과에서 그대로 붙입니다.
공부 순서·오답노트와 요약 노트를 브라우저로 바로 열리는 HTML 파일 두 개로 내려받습니다.

**결과 예시**: 앱을 열지 않고 결과를 읽으려면 [docs/결과_예시/README.md](docs/결과_예시/README.md)를 보세요.

## 사용 방법

앱이 잠들어 있으면 첫 화면에 "This app has gone to sleep"이 보입니다. **Yes, get this app back up!**을 누르고 30초쯤 기다리면 열립니다.

1. **샘플로 체험**: 파일 없이 "샘플로 체험"을 누르면 직접 만든 가상 강의자료(자료구조 8장, 20쪽)와 대본으로 분석합니다.
   ③에서 문제를 다 풀 시간이 없으면 **예시 답 채우기 (샘플 체험용)**를 누르고 채점하세요.
2. **내 자료 올리기**: 강의자료 PDF/PPTX(30MB까지)를 올리고 "분석 시작".
3. **녹음 대신 대본 붙여넣기**: 녹음 파일(m4a/mp3/wav, 25MB까지) 대신 받아쓴 대본을 "대본 붙여넣기" 탭에 넣어도 됩니다. 둘 다 없어도 자료만으로 동작합니다.
4. **빠른 진단**: ②에서 "빠른 진단"을 켜면 출제 가능성 상위 5개만 풀고 나머지는 '진단 안 함'으로 계산합니다.
5. **분석 횟수 제한**: 배포 앱은 키 하나를 함께 쓰므로 분석은 화면(브라우저 탭) 하나에서 5번, 서버 전체 하루 150번까지입니다.

## 어떻게 동작하나

```text
자료 → 텍스트 추출·마스킹(코드) → 개념 추출(AI 1) → 강조 발화(AI 2) → 출제 점수(코드)
     → 진단 문제(AI 3-A 서술형 / 3-C 객관식) → 채점(객관식 코드, 서술형 AI 3-B) → 우선순위(코드)
     → 보완 설명(AI 4) · 요약 노트(AI 5) → HTML 내보내기(코드)
```

AI 호출은 모두 `core/llm.py`의 `ask_json()` 하나를 거치고, 프롬프트는 `prompts/*.md`에서 읽습니다. 호출 3·4·5에는 그 개념이 나오는 쪽 텍스트만(최대 8쪽) 넣습니다.

출제 가능성 점수 가중치 v0 (`core/score.py` 맨 위 `WEIGHTS`):

| 신호 | 점수 |
|---|---|
| 학습목표에 있음 | +3.0 |
| 본문 쪽수 (메타 페이지 제외) | 쪽당 +1.0, 최대 +4.0 |
| 예제·그림으로 과정 설명 | +1.5 |
| 연습문제에 포함 | +2.0 |
| 강조 발화 | +1.0 × (강도/3), 발화마다 |
| 시험 암시 | +1.5 × (강도/3) |
| 실수 경고 | +0.7 × (강도/3) |
| 연습문제 지목 | +1.0 × (강도/3) |
| 다음에 다룸 | −2.5 |
| 가볍게 넘어감 | −1.0 |

가장 높은 개념을 100점으로 맞춘 비교용 점수이며 확률이 아닙니다.
우선순위 = 출제 점수 × (1 − 이해도). 이해도는 앎 1.0, 헷갈림 0.5, 모름 0.0, 진단 안 함 0.5. 50 이상 지금 당장, 20~49 다음, 20 미만 복습만.

모델: `claude-sonnet-5-5`. 바꾸려면 `config.py`의 `LLM_MODEL` 한 줄만 고칩니다. 음성 인식은 OpenAI 전사 API(`STT_MODEL`)를 쓰고, 키가 없으면 대본 붙여넣기만 됩니다.

## 로컬 실행

```bash
python -m pip install -r requirements.txt
```

`.streamlit/secrets.toml` 파일을 만들고 아래 키 이름에 값을 넣습니다(이 파일은 `.gitignore`에 있어 올라가지 않습니다).

```toml
ANTHROPIC_API_KEY = "..."
OPENAI_API_KEY = "..."   # 녹음 받아쓰기를 쓸 때만
```

```bash
python -m streamlit run app.py
```

키 없이 화면만 보려면 `BINTM_FAKE_AI=1`을 켜고 실행합니다(저장된 결과로 답하는 가짜 AI 모드).

## 한계와 향후 계획

- 스캔 PDF(글자가 그림인 PDF)는 읽지 못합니다. 글자 인식은 향후 계획입니다.
- 한 번에 한 장(chapter) 단위를 전제로 합니다. 120쪽을 넘으면 앞 120쪽만 분석합니다.
- 녹음은 25MB까지입니다.
- 출제 가능성 점수는 규칙 기반 추정입니다. 가중치 v0은 샘플 자료로 맞춘 값이며 기출 비교로 조정할 수 있습니다(`scripts/compare_exam.py`).
- 분석 횟수는 서버 메모리에서 세므로 서버가 다시 켜지면 하루 횟수가 0부터 다시 셉니다.
- 모델은 `config.py` 한 줄로 바꿀 수 있습니다. 학우 질문 기록 기능은 아직 없습니다.

## 데이터 처리·저작권·녹음 동의

- 올린 자료와 녹음은 분석을 위해 AI 제공사(Anthropic, OpenAI) 서버로 전송됩니다.
- 올린 파일은 서버 디스크에 저장하지 않습니다. 결과는 브라우저 탭의 세션에 두고, 같은 파일을 다시 분석할 때를 위해 개념·강조 분석 결과와 쪽 그림만 서버 메모리 캐시에 잠시 둡니다(서버가 다시 켜지면 사라짐). 녹음 받아쓰기용 임시 파일은 보낸 직후 지웁니다.
- 학번(숫자 8~10자리)·전화번호·이메일은 강의자료와 대본 모두 AI에 보내기 전에 `[마스킹]`으로 가립니다.
- 녹음은 교수님 허락을 받은 것만, 개인 학습 목적으로만 올려 주세요.
- 저장소의 `samples/`는 우리가 직접 만든 가상 강의자료와 대본입니다. 실제 교재·녹음·기출 문제는 저장소에 넣지 않습니다.
