# 빈틈노트

**강의자료와 교수님 강조점, 메타인지 진단으로 시험 전 공부 우선순위를 정해주는 AI 서비스**

- 저장소: https://github.com/dodohun2212/bintm-rehearsal

## 요약
- **문제**: 시험 전에 자료는 많고 시간은 없다. 교수님이 "이건 꼭 알아두세요"라고 한 말은 녹음 속에 묻혀 있고, 안다고 생각한 것과 실제로 아는 것은 다르다.
- **누구를 위해**: 강의자료와 수업 대본으로 시험을 준비하는 대학생
- **어떻게**: ① 출제 포인트 레이더 ② 객관식 메타인지 진단(찍어서 맞힌 것은 헷갈림) ③ 출제 가능성 × 모르는 정도로 공부 순서와 쪽 인용 보완 설명
- **바로 써 보기**: 배포 URL → "샘플 자료로 체험하기" → "n개 개념 진단하기" → "예시 답 채우기" → "채점하기" → "공부 순서 보기". (실제 AI로 끝까지 돌린 시간은 아직 재지 않았어요)

## English summary
Bintm Note (빈틈노트) helps university students decide what to study first before an exam.
Upload lecture slides (PDF/PPTX) and, optionally, a transcript of the lecture.
The app ranks likely exam concepts with visible evidence (learning objectives, pages, examples, exercises, the professor's emphasis),
checks real understanding with one multiple-choice question per top concept (a correct guess counts as "confused"),
and builds a study order (exam score × gap in understanding) with page-cited explanations.

## 사용 방법
1. 강의자료(PDF/PPTX)를 올리고, 있으면 교수님 강의 대본을 붙여 넣어요. 자료가 없으면 "샘플 자료로 체험하기"를 눌러요.
2. 출제 포인트 레이더에서 시험에 나올 가능성이 높은 개념과 근거(학습목표, 본문 쪽, 예제, 연습문제, 교수님 강조)를 봐요.
3. 상위 개념마다 객관식 1문제를 풀어요. 모르면 "모르겠어요", 찍었으면 "확신 없이 골랐어요"를 체크해요.
4. 채점 결과로 정한 공부 순서와 쪽 번호가 붙은 보완 설명을 보고, 결과를 마크다운으로 내려받아요.

## 어떻게 동작하나
- AI는 읽고 분류하고 문제·설명을 쓰는 일만, 점수·순위·이해 상태는 코드가 계산해요 (같은 입력 → 같은 점수).
- 흐름: 자료 → AI① 개념 추출 / 대본 → AI② 강조 발화 → [코드] 출제 가능성 → AI③ 객관식 → [코드] 채점·이해도·우선순위 → AI④ 보완 설명

출제 가능성 점수 (개념마다 더한 뒤, 음수는 0, 최고점을 100으로 맞춘 0~100 정수):

| 신호 | 점수 |
|---|---|
| 학습목표에 있음 | +3.0 |
| 본문 쪽수 (메타 쪽 제외) | 쪽당 +1.0, 최대 +4.0 |
| 예제·그림으로 과정 설명 | +1.5 |
| 연습문제에 포함 | +2.0 |
| 강조 발화 `emphasis` | +1.0 × 강도/3 |
| 시험 암시 `exam_hint` | +1.5 × 강도/3 |
| 실수 경고 `mistake` | +0.7 × 강도/3 |
| 연습문제 지목 `exercise_point` | +1.0 × 강도/3 |
| 다음에 다룸 `defer` | −2.5 |
| 가볍게 넘어감 `skip` | −1.0 |

이해도와 우선순위:

| 답 | 상태 | 이해도 |
|---|---|---|
| 정답 + 확신 | 앎 | 1.0 |
| 정답 + "확신 없이 골랐어요" | 헷갈림 | 0.5 |
| 오답 / "모르겠어요" | 모름 | 0.0 |
| 진단 안 함 (20점 미만이거나 상위 6개 밖) | 진단 안 함 | 0.5 |

- 우선순위 = 출제 점수 × (1 − 이해도). 50 이상 "지금 당장", 20 이상 "다음", 그 밖은 "복습만".
- AI 응답은 JSON으로 받아 형식 검사(목록에서 형식이 틀린 항목은 그 항목만 버리고 계속), 인용 문장은 대본에 실제로 있는지, 인용 쪽은 입력 범위 안인지 코드가 확인해요. 객관식 보기는 개념 id를 시드로 섞어 정답 위치가 몰리지 않게 해요.
- 모델: Anthropic `claude-sonnet-5-5` (`core.py`의 `MODEL` 한 줄로 교체)
