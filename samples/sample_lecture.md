=== p.2 ===
학습 목표

=== p.3 ===
8.1 트리의 용어
트리: 계층 관계를 표현하는 비선형 자료구조 (예: 폴더 구조, 조직도)
루트: 가장 위의 노드. 부모·자식: 간선으로 연결된 위·아래 노드
단말 노드(leaf): 자식이 없는 노드. 서브트리: 한 노드와 그 자손 전체
깊이: 루트에서 그 노드까지의 간선 수 (루트의 깊이 = 0)
높이: 그 노드에서 가장 먼 단말 노드까지의 간선 수 (단말 노드의 높이 = 0)
예: A의 자식 B, C / B의 자식 D, E / C의 자식 F 일 때 E의 깊이 2, 높이 0, 트리의 높이 2

=== p.4 ===
8.2 이진 트리와 배열 표현
이진 트리: 모든 노드의 자식이 최대 2개
완전 이진 트리: 마지막 레벨을 빼고 꽉 차 있고, 마지막 레벨은 왼쪽부터 채움 → 힙에서 사용
배열 표현(루트를 인덱스 1에): 노드 i의 왼쪽 자식 2i, 오른쪽 자식 2i+1, 부모 i // 2
예: [_, A, B, C, D, E, F] 에서 E(인덱스 5)의 부모는 5 // 2 = 2 → B

=== p.5 ===
8.3 이진 트리의 순회
전위(preorder): V → L → R / 중위(inorder): L → V → R / 후위(postorder): L → R → V
예제: 수식 트리 (+ 루트, 왼쪽 * (a, b), 오른쪽 - (c, d))
전위: + * a b - c d / 중위: a * b + c - d / 후위: a b * c d - +
수식 트리를 후위 순회하면 후위 표기식이 된다. 시간 복잡도 O(n)

=== p.6 ===
8.4 이진 탐색 트리(BST)
모든 노드에서 왼쪽 서브트리 < 노드 < 오른쪽 서브트리
중위 순회하면 오름차순: 예) 35, 18, 68, 7, 26, 50, 99를 차례로 삽입 → 중위 순회 7 18 26 35 50 68 99
탐색: 루트부터 작으면 왼쪽, 크면 오른쪽. 삽입: 탐색이 실패한 자리에 붙임 → 항상 단말 노드로 삽입
시간 복잡도 O(h): 균형이면 O(log n), 한쪽으로 치우치면 O(n)

=== p.7 ===
BST의 삭제
경우 1 단말 노드: 그냥 제거 / 경우 2 자식 하나: 그 자식을 부모에 연결

=== p.8 ===
8.5 힙
힙: 완전 이진 트리 + 힙 조건. 최대 힙은 부모 ≥ 자식(루트가 최댓값), 최소 힙은 부모 ≤ 자식
형제 사이에는 순서가 없다 (정렬된 것이 아님). 배열로 표현한다
예: 최대 힙 [_, 93, 80, 75, 50, 62, 70, 33]

=== p.9 ===
힙의 삽입 (업힙)
1) 새 항목을 마지막 위치(배열 끝)에 넣는다 → 완전 이진 트리 유지
2) 부모보다 크면 부모와 교환, 루트에 닿거나 부모보다 작아질 때까지 반복
예제: 최대 힙 [_, 90, 70, 80, 40, 60]에 85 삽입 → 85는 인덱스 6, 부모 80과 교환, 부모 90보다 작아 멈춤 → [_, 90, 70, 85, 40, 60, 80]
시간 복잡도 O(log n): 트리 높이만큼만 올라간다

=== p.10 ===
힙의 삭제 (다운힙)
1) 루트(최댓값)를 꺼낸다 2) 마지막 노드를 루트 자리로 옮긴다
3) 두 자식 중 더 큰 자식과 비교해 작으면 교환, 단말에 닿거나 두 자식보다 크면 멈춤
더 큰 자식과 바꾸는 이유: 작은 자식과 바꾸면 새 부모가 다른 자식보다 작아져 힙 조건이 깨진다
시간 복잡도 O(log n)

=== p.11 ===
8.6 우선순위 큐
들어온 순서가 아니라 우선순위가 가장 높은 항목부터 꺼내는 큐
구현 비교 (삽입 / 최댓값 삭제): 정렬 안 된 배열 O(1) / O(n), 정렬된 배열 O(n) / O(1), 힙 O(log n) / O(log n)
→ 삽입과 삭제가 섞여 많이 일어나면 힙이 가장 유리하다
