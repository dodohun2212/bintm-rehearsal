1. 힙의 삭제 연산 모름출제 점수 86우선순위 86
아래 트리는 최대 힙이다. 루트(50)를 삭제한 뒤의 힙을 배열(레벨 순서)로 쓰시오. 그리고 마지막 노드를 루트로 옮긴 다음 첫 교환에서 왼쪽 자식 40이 아니라 오른쪽 자식 45와 교환하는 이유를 쓰시오.
최대 힙
내 답
모르겠어요
채점 모름 0/10 · 무응답 — '모르겠어요'를 골라 모름으로 표시했어요.
모범 답안

삭제 후 힙은 [45, 40, 35, 30, 20, 10]이다. 마지막 노드 10을 루트로 옮긴 뒤 두 자식 중 더 큰 자식과 교환하며 내려가는데, 40과 45 중 더 큰 45를 올려야 새 루트가 두 자식보다 크거나 같아져 최대 힙 조건이 유지되기 때문이다.

  • 삭제 후 배열을 [45, 40, 35, 30, 20, 10]으로 정확히 씀 (5점)
  • 두 자식 중 더 큰 자식과 교환한다고 설명함 (3점)
  • 더 큰 자식을 올려야 부모가 자식보다 크다는 힙 조건이 유지된다는 이유를 씀 (2점)
문제 근거 p.16p.17

보완 설명

내가 놓친 점 '모르겠어요'를 골라 삭제 후 배열이 어떻게 되는지와, 첫 교환에서 왼쪽 자식 40이 아닌 오른쪽 자식 45를 고르는 이유를 아직 답하지 못했다.

힙에서 삭제는 '항상 루트(최댓값)를 꺼내는 것'이다p.16. 그러므로 이 문제에서 꺼내는 값은 루트 50이다.

절차는 두 단계다. '① 루트를 꺼내고, 마지막 노드를 루트 자리로 옮긴다'p.16. 이 문제에서는 마지막 노드 10이 루트 자리로 올라간다. 이어서 '② 두 자식 중 더 큰 자식과 비교해 작으면 교환하며 내려간다 (다운힙, sift-down)'p.16. 따라서 첫 교환의 상대는 왼쪽·오른쪽 위치와 상관없이 두 자식 40, 45 중 더 큰 45이다.

코드에도 같은 규칙이 있다. 두 자식 중 왼쪽이 오른쪽보다 작으면 'child += 1'로 오른쪽을 고르며, 주석은 '더 큰 자식 선택'이다p.17. 이어서 'if last >= self.heap[child]: break'로 내려온 값이 자식 이상이면 멈추고, 아니면 자식을 부모 자리로 올린다p.17. 이렇게 큰 자식이 위로 올라오면 새 루트가 두 자식보다 크거나 같게 유지된다.

자료의 예시도 같은 흐름이다. 93을 삭제하고 33을 루트로 옮긴 뒤 '80, 62와 교환하며 내려감 → 결과 [80, 62, 75, 50, 33, 70]'이다p.16. 시간 복잡도는 O(log n)이다p.16.

2. 우선순위 큐와 힙 구현 모름출제 점수 51우선순위 51
우선순위 큐를 '정렬된 배열'로 구현할 때와 '힙'으로 구현할 때, 삽입과 최댓값 삭제의 시간 복잡도를 각각 비교하시오. 그리고 이 비교를 근거로 우선순위 큐를 힙으로 구현하는 것이 유리한 이유를 쓰시오.
내 답
모르겠어요
채점 모름 0/10 · 무응답 — '모르겠어요'를 골라 모름으로 표시했어요.
모범 답안

정렬된 배열은 삽입이 O(n), 최댓값 삭제가 O(1)이고, 힙은 삽입과 삭제가 모두 O(log n)이다. 정렬된 배열은 한 연산만 빠르고 다른 연산은 O(n)으로 느리지만, 힙은 두 연산이 모두 O(log n)으로 균형 있게 빠르기 때문에 우선순위 큐 구현에 유리하다.

  • 정렬된 배열의 시간 복잡도를 바르게 쓴다 (삽입 O(n), 삭제 O(1)) (3점)
  • 힙의 시간 복잡도를 바르게 쓴다 (삽입 O(log n), 삭제 O(log n)) (3점)
  • 정렬된 배열은 한 연산이 O(n)으로 느린 반면 힙은 두 연산 모두 O(log n)이라는 점을 근거로 힙이 유리한 이유를 설명한다 (4점)
문제 근거 p.18p.19

보완 설명

내가 놓친 점 '모르겠어요'를 골라, 정렬된 배열과 힙에서 삽입과 최댓값 삭제의 시간 복잡도가 각각 얼마인지, 그리고 이를 근거로 힙이 유리한 이유를 아직 답하지 못했다.

먼저 두 구현의 시간 복잡도를 구분해야 한다. 자료의 표에 따르면 정렬된 배열은 삽입이 O(n), 삭제(최댓값)가 O(1)이고, 힙은 삽입이 O(log n), 삭제(최댓값)가 O(log n)이다p.18.

이 표에서 정렬된 배열은 한 연산만 O(1)로 빠르고 다른 연산은 O(n)이다. 자료도 '배열·연결 리스트는 둘 중 하나가 O(n)'이라고 쓰고 있다p.18. 정렬 안 된 배열은 삽입이 O(1), 삭제가 O(n)으로 역시 한쪽이 느리다p.18.

힙이 유리한 이유는 두 연산이 모두 빠르기 때문이다. 자료는 '힙으로 구현하면 두 연산 모두 O(log n)'이라고 설명한다p.18. 요약에서도 '힙 삽입 = 마지막에 넣고 업힙, 힙 삭제 = 루트 꺼내고 마지막을 올려 다운힙, 둘 다 O(log n)'이라고 정리한다p.20.

따라서 답안에는 정렬된 배열의 O(n)과 O(1), 힙의 O(log n)과 O(log n)을 먼저 적는다. 그 뒤 '한 연산이 O(n)인 배열과 달리 힙은 삽입과 삭제가 모두 O(log n)이다'라는 결론을 잇는다.

3. 이진 트리의 순회 헷갈림출제 점수 90우선순위 45
아래 이진 트리를 전위 순회했을 때의 방문 순서를 쓰시오. 또한 후위 순회에서는 루트 A가 몇 번째로 방문되는지 그 이유와 함께 쓰시오.
이진 트리
내 답
전위 순회(V → L → R)의 방문 순서는 A B D E C F이다.
채점 헷갈림 4/10 · 절차 누락 — 전위 순회 결과 A B D E C F는 문제의 그림과 p.8의 V → L → R 정의에 모두 맞다. 그러나 후위 순회에서 루트 A가 마지막(여섯 번째)에 방문된다는 내용과 그 이유(L → R → V, p.8)가 답안에 없다.
모범 답안

전위 순회(V → L → R)의 방문 순서는 A B D E C F이다. 후위 순회(L → R → V)에서는 왼쪽·오른쪽 서브트리를 모두 방문한 뒤에 루트를 방문하므로, 루트 A는 가장 마지막(여섯 번째)에 방문된다(D E B F C A).

  • 전위 순회 결과를 A B D E C F로 정확히 쓴다 (4점)
  • 후위 순회에서 루트 A가 가장 마지막에 방문된다고 쓴다 (3점)
  • 후위 순회는 왼쪽·오른쪽 서브트리를 먼저 방문한 뒤 루트를 방문하기 때문(L → R → V)이라고 이유를 설명한다 (3점)
문제 근거 p.8p.10

보완 설명

내가 놓친 점 전위 순회 결과는 맞게 썼지만, 후위 순회에서 루트 A가 몇 번째로 방문되는지와 그 이유(L → R → V에서 루트는 마지막)를 답하지 못했다.

후위 순회는 루트(V)를 가장 나중에 방문하는 방식이다. 자료는 '후위 순회(postorder): L → R → V'p.8라고 정의하며, 루트를 언제 방문하느냐에 따라 세 가지 순회가 나뉜다고 설명한다p.8. 따라서 후위 순회에서는 왼쪽(L)과 오른쪽(R) 서브트리를 모두 방문한 뒤에야 루트를 방문한다.

이 규칙을 문제의 트리에 적용하면 왼쪽 서브트리인 B 쪽(D, E, B)을 먼저 방문하고, 오른쪽 서브트리인 C 쪽(F, C)을 방문한 뒤 마지막에 A를 방문한다. 방문 순서는 D E B F C A이고, 노드가 6개이므로 루트 A는 여섯 번째, 즉 마지막이다.

이 규칙은 코드로도 확인된다. 자료의 postorder 함수는 'postorder(n.left)', 'postorder(n.right)'를 차례로 호출한 뒤 마지막에 'print(n.data, end=' ')'를 실행한다p.10. 요약에서도 '이진 트리 순회: 전위 VLR, 중위 LVR, 후위 LRV'p.20로 정리하므로, V의 위치가 앞이면 전위, 가운데면 중위, 마지막이면 후위로 구분하면 된다.

해설

자료는 루트를 인덱스 1에 둘 때 노드 i의 왼쪽 자식은 2i, 부모는 i // 2라고 설명한다p.7. E는 인덱스 5이므로 부모는 5 // 2 = 2번인 B이고, 왼쪽 자식은 2×5 = 10번이다. 인덱스 11은 루트를 0에 두는 방식의 계산이라 이 배열에는 맞지 않는다.

보완 설명

내가 놓친 점 정답인 보기를 골랐지만 부모 = i // 2, 왼쪽 자식 = 2i라는 규칙을 확신하지 못했고, 오른쪽 자식 2i+1이나 형제 노드와 어떻게 다른지 구분하지 못했다.
💬 내가 헷갈린 점에 대한 답
내가 적은 글: 두 보기 사이에서 고민했어요. 둘이 어떻게 다른지 모르겠어요.

어떤 두 보기를 두고 고민했는지는 적혀 있지 않아 알 수 없지만, 보기들은 부모 노드와 왼쪽 자식 인덱스 두 군데에서 갈린다. 자식 인덱스가 10인지 11인지는 왼쪽인지 오른쪽인지의 차이다. 자료에서 "왼쪽 자식 = 2i, 오른쪽 자식 = 2i+1"p.7이므로 11은 오른쪽 자식 규칙에 해당하고, 문제가 묻는 왼쪽 자식은 2×5 = 10이다. 부모는 "부모 = i // 2"p.7로 구하므로 인덱스 2인 B이고, D는 배열에서 인덱스 4에 있어 이 계산으로 나오지 않는다.

자료는 루트를 인덱스 1에 두고 저장하는 규칙을 "노드 i의 왼쪽 자식 = 2i, 오른쪽 자식 = 2i+1, 부모 = i // 2"p.7라고 정리한다. 왼쪽 자식은 2i, 오른쪽 자식은 2i+1로 서로 다르고, 부모는 i를 2로 나눈 몫이다.

이 규칙을 E에 적용한다. 배열에서 E는 인덱스 5에 있으므로 부모는 5 // 2 = 2번인 B이고, 왼쪽 자식은 2×5 = 10번이다. 따라서 "부모는 B이고, 왼쪽 자식은 인덱스 10에 저장된다"가 맞다.

자료는 "인덱스 0은 비워 둠"p.7이라고 적어, 계산이 인덱스 1부터 시작한다는 점을 분명히 한다. 이 표기는 힙에서도 같아서 "완전 이진 트리이므로 배열로 표현한다 (부모 i → 자식 2i, 2i+1)"p.14로 다시 나온다.
