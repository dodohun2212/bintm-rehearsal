# 결과 예시 (샘플 자료, 배포 앱에서 내려받은 파일)

이 PC에 AI 키 파일이 없어, 배포 앱에서 실제 AI로 샘플 한 바퀴(샘플 체험 → 진단 → 예시 답 채우기 → 채점 → 공부 순서 → 요약 노트)를 돌린 뒤 ④의 내려받기 버튼 두 개가 준 HTML을 그대로 넣었어요. 마크다운은 `python scripts/make_example.py --from-html 빈틈노트_공부순서_오답노트_2026-11-11.html 빈틈노트_요약노트_2026-11-11.html`로 만들었어요.

- 만든 날: 2026-11-11 (한국 시간)
- 모델: `claude-sonnet-5-5` (배포 앱 설정)
- 공부 순서: 지금 당장 2, 다음 3, 복습만 8
- 요약 노트: 자세히 7, 보통 1, 짧게 5
