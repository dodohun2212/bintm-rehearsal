# 결과 예시 (샘플 자료)

앱을 열지 않고도 결과를 읽을 수 있게, 샘플 자료(가상 강의자료 20쪽 + 대본)로 한 바퀴 돌린 결과입니다. 출제를 보장하지 않습니다. 공부 우선순위를 정하는 참고용입니다.

- 만든 날: 2026-11-11
- 만든 방법: 배포 앱에서 샘플 체험 → 예시 답 채우기 → 채점 → ④ 내려받기 2개(실제 AI)
- 모델: claude-sonnet-5-5

잰 값(배포 앱 ⑤ 사용량, 2026-11-11, 커밋 0aed1c4): 개념 14개, 진단 문제 12개(서술형 5 · 객관식 7), 예시 답 채우기 결과 앎 5 · 헷갈림 4 · 모름 3, AI 호출 33번, 입력 122,303 · 출력 50,152 토큰, 단계별 시간 분석 39.3초 · 문제 만들기 27.6초 · 채점 4.0초 · 보완 설명 9.1초 · 요약 노트 26.5초(합 106.5초), 실패 0. 이 PC에 키 파일이 없어 scripts/make_example.py로 실제 AI를 돌리지 못했고, 배포 앱에서 같은 순서로 돌려 내려받은 HTML 2개를 그대로 넣고 마크다운으로 바꿨습니다.
