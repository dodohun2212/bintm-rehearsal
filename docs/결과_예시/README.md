# 결과 예시 (샘플 자료)

## 만든 조건과 잰 값

- 만든 날: 2026-11-11
- 만든 방법: 배포 앱(https://bintm-rehearsal-myagsiaqtsuzkjjrnnrpgc.streamlit.app)에서 샘플로 체험 → 10개 개념 진단하기(섞어서) → 예시 답 채우기 → 채점 → 공부 순서 보기 후, 두 내려받기 버튼이 준 파일을 그대로 저장. 이 PC에 키 파일(.streamlit/secrets.toml)이 없어 scripts/make_example.py로 직접 돌리지 못했기 때문
- 모델: claude-sonnet-5-5 (배포 앱 설정)
- 실패: 0개
- 개념 13개, 교수님 강조 발화 27개(② 숫자 칸)
- 출제 가능성 상위 3개: 힙의 삽입 연산 100점, 이진 트리의 순회 90점, 힙의 삭제 연산 86점 · 이진 탐색 트리의 삭제 0점(맨 끝)
- 진단 문제 10개(서술형 6 · 객관식 4), 진단 결과: 앎 4 · 헷갈림 3 · 모름 3
- 단계별 시간(앱 ⑤ 화면): 분석 57.2초 · 문제 만들기 21.5초 · 채점 4.2초 · ④ 설명·노트 25.4초
- AI 호출 28번 · 입력 104,637 토큰 · 출력 46,987 토큰(앱 ⑤ 화면의 이번 세션 사용량)
- 파일 안의 날짜 2026-11-10은 그때 앱이 서버(UTC) 날짜를 쓰던 버그 때문이며, 이후 한국 날짜로 고쳤다

다시 만들기: `python scripts/make_example.py` (키 필요, 약 2분)
