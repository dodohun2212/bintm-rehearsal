# 결과 예시 (샘플 자료)

## 만든 방법

- 배포 URL(https://bintm-rehearsal-myagsiaqtsuzkjjrnnrpgc.streamlit.app)에서 버튼을 눌러 내려받은 HTML 2개를 그대로 넣었습니다. 키는 배포 앱의 Streamlit Cloud Secrets에 있는 것만 썼고, 이 PC에는 API 키를 두지 않았습니다.
- 마크다운 2개는 HTML을 `scripts/make_example.py`의 `html_to_md()`로 바꾼 것입니다.
- 이 PC에 키가 있으면 `python scripts/make_example.py`로 앱 없이 같은 순서를 돌려 이 폴더를 다시 만들 수 있습니다.

## 만든 조건과 잰 값

- 만든 때: 2026-11-11 01:22 (한국 시간). 파일 안 날짜가 2026-11-10인 것은 배포 서버가 세계 표준시(UTC)로 날짜를 적기 때문입니다.
- 모델: `claude-sonnet-5-5`
- 개념 13개, 진단 문제 11개(서술형 6 · 객관식 5)
- 예시 답 채점 결과: 앎 4 · 헷갈림 4 · 모름 3
- 공부 순서: 지금 당장 2 · 다음 3 · 복습만 8
- 보완 설명 5개("내가 헷갈린 점에 대한 답" 2개 포함), 요약 노트 13개(자세히 7 · 보통 2 · 짧게 4)
- 실패: 0 (화면과 파일에 오류 코드 없음)
- AI 호출 18번, 입력 64,707 토큰, 출력 27,616 토큰 (앱 ⑤ 화면 "이번 세션 사용량").
  분석(개념·강조)과 진단 문제는 2026-11-10 23:35에 같은 배포 앱에서 실제 AI로 만든 결과가 서버 캐시에 남아 있어 다시 썼고, 이 두 단계에서는 AI를 부르지 않았습니다.

| 단계 | 걸린 시간(초) |
|---|---|
| 샘플로 체험 → ② (서버 캐시) | 1.0 |
| 진단 문제 만들기 (샘플 문제 재사용) | 1.0 |
| 예시 답 채우기 → 채점 | 5.0 |
| 공부 순서 보기 → ④ (보완 설명·요약 노트) | 30.4 |

버튼을 누른 때부터 다음 화면 글이 나타날 때까지를 브라우저에서 쟀습니다. 캐시가 없을 때 처음부터 돌린 시간은 저장소 맨 위 README의 "배포 앱에서 실제 AI로 샘플 한 바퀴" 표에 있습니다.
